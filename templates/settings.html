Le moteur utilisé par la page Assistant IA et la catégorisation automatique.

Moteur d'IA
{# ---- Ollama ---- #}

Adresse d'Ollama

Modifiable dans le fichier .env (OLLAMA_URL).

Pour installer Ollama : ollama.com/download, puis dans un terminal ollama pull llama3.1. Sur un Mac avec 8 Go de mémoire, préférez un petit modèle (par exemple llama3.2).

{# ---- Claude ---- #}

Utilise le compte Claude déjà connecté dans Claude Code sur ce Mac, sans clé à saisir. Claude répond seulement au texte reçu : il ne peut ni lire vos fichiers ni lancer de commandes. Si la détection échoue, tapez which claude dans un terminal et collez le chemin ici.

Clé à créer dans la Claude Console. L'API est facturée à l'usage, séparément d'un abonnement Claude. La clé reste dans la base de ce Mac.

Ce qui est envoyé à Anthropic

  • Vos questions et les réponses précédentes de la conversation.
  • Un résumé chiffré : totaux par mois, par catégorie, par type de compte et par type d'actif, état des budgets.
  • Jamais : libellés d'opérations, noms de comptes, de banques, de positions ou d'objectifs.
  • Exception : la catégorisation automatique envoie les libellés concernés, après confirmation.
